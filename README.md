# Wiz Research Public IOC Database

This repo contains public indicators of compromise aggregated by Wiz Research.

## Tooling

[`scripts/scan_npm_lockfile.py`](scripts/scan_npm_lockfile.py) checks an npm or
pnpm lockfile against the malicious-package CSVs in this repo. See
[`scripts/README.md`](scripts/README.md) for usage.
